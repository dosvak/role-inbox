# Role Inbox (RLINBX)

The inbox of one role across every application: my teams are resolved from my memberships, each with its open / unassigned / mine counts and the applications involved; a click lists the tasks of that team across applications (all, unassigned only, or assigned to me); selected tasks can be claimed (assigned to me) or released back to the team; every row carries the open-task link of Process Portal. Complements Task Lists (which filters by application).

**Target:** IBM BPM 8.6.2, IBM BAW 20-26 (traditional) and CP4BA (Workflow Authoring / Studio import). Built from out-of-the-box building blocks only (System Data, UI Toolkit, one client-side human service,
server-side service flows calling the product REST API as a technical user; where no API exists, a read-only SELECT on the product
database through the engine's own datasource) - no third-party toolkit, no custom Java.

## Install

1. Import `packages/Role-Inbox-1.0.twx` (Process Center / Workflow Center console: *Import Process App*; CP4BA: Business Automation Studio > *Import*).
2. Set the environment variables of the snapshot (below): the server base URL as seen from the server itself and the technical user the
   flows call the REST API with. The package ships no password.
3. Expose the dashboard to a team (the package's default team holds `celladmin`; change it) and open it from Process Portal or the
   playback URL of the human service.

## Dashboard

| Tab | Content |
|---|---|
| Inbox | user (empty = me), My teams; team table (row click lists tasks); team name, mode, List tasks, Claim selected, Release selected, Export CSV; task table |

## Environment variables

`serverBaseURL`, `restAuthUser`, `restAuthPassword`, `restTrustAllCertificates`, `appTitle`, `portalBaseURL` (open-task links).

## Rebuilding and customising

The application is generated by a small Python program on the twxkit generator (standard library only, no base export). The generator
and the kit are served to AI agents and developers by the **BAW Knowledge MCP server** (`https://bawmcp.dosvak.com/mcp`, see
[dosvak/baw-mcp](https://github.com/dosvak/baw-mcp)): `get_package('role inbox (rlinbx)')` returns this package, `get_tool('build_rlinbx.py')`
the generator, `get_topic('howto-kit-utility-app-recipes')` the recipes.
