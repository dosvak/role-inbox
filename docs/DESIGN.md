# Role Inbox (RLINBX) - process application

The inbox of one role across every application: my teams are resolved from my memberships, each with its open / unassigned / mine counts and the applications involved; a click lists the tasks of that team across applications (all, unassigned only, or assigned to me); selected tasks can be claimed (assigned to me) or released back to the team; every row carries the open-task link of Process Portal. Complements Task Lists (which filters by application).

Package `Role-Inbox-1.0.twx` (generated by `tools/build_rlinbx.py` on twxkit + kitlib, standard library only, no base export); targets: 8.6.2, BAW 20-26 (classic v1 API).
Vanilla BAW: UI Toolkit controls only, one client-side human service, server-side service flows calling the REST API (and, where no
API exists, the product database read-only through the engine's datasource) with the technical user of the environment variables.

## Dashboard

| Tab | Content |
|---|---|
| Inbox | user (empty = me), My teams; team table (row click lists tasks); team name, mode, List tasks, Claim selected, Release selected, Export CSV; task table |

Every list has a status line; errors open a message modal; CSV export shows the text in a modal for copy / paste.

## Service flows, REST calls and SQL

| Flow | Does |
|---|---|
| RI My Teams | `GET /user/{login}?includeInternalMemberships=true` -> memberships `<Team>_T_<team uuid>.<snapshot uuid>` -> team names; `PUT /search/query` byTask open tasks -> counts per team (open, unassigned, mine) |
| RI Team Tasks | open tasks filtered by `assignedToRoleDisplayName` = team and the mode; link `<portalBaseURL>/teamworks/process.lsw?zWorkflowState=1&zTaskId=<id>` |
| RI Claim Release | `PUT /task/{id}?action=assign&toUser=<login>` or `&back=true` |
| RI Rows To CSV | rows -> CSV |

## Environment variables

`serverBaseURL`, `restAuthUser`, `restAuthPassword`, `restTrustAllCertificates`, `appTitle`, `portalBaseURL` (open-task links).

## Business objects

RIQuery, RITeamRow, RITeams, RITaskRow, RITasks, RIAssign, RIAction, RICsv.

## Pitfalls met

* The task search index lags a few seconds behind an assignment: "assigned to me" right after a claim may still show the previous state.
* Team names come from `assignedToRoleDisplayName` of the tasks and from the membership pattern; a team with no open task appears with zero counts, a task of a team the user is not a member of never appears.
